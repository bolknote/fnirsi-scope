# FNIRSI Scope

[English](README.md) · Русский

FNIRSI Scope — настольное приложение для осциллографа **FNIRSI 2C53T**. Оно показывает оба канала по USB, измеряет сигнал, записывает серию кадров по триггеру и накладывает сохранённые кадры друг на друга. Приложение работает на macOS, Linux и Windows. Для управления по USB нужна модификация прошивки **r6j** из этого репозитория.

Это независимый проект Евгения Степанищева (Evgeny Stepanischev).

## Скачать приложение

Откройте [GitHub Releases](https://github.com/bolknote/fnirsi-scope/releases) и выберите файл для своего компьютера.

| Компьютер | Архив | Что открыть |
| --- | --- | --- |
| Mac с Apple Silicon | `macos-arm64.zip` | `fnirsi_scope.app` |
| Mac с Intel | `macos-x64.zip` | `fnirsi_scope.app` |
| 64-битный Linux (x86-64) | `linux-x64.tar.gz` | `./fnirsi_scope` в распакованной папке |
| 64-битная Windows 10 или 11 (x86-64) | `windows-x64.zip` | `fnirsi_scope.exe` в распакованной папке |

Распакуйте архив целиком. Оставьте соседние файлы рядом с приложением.

- **macOS 12 или новее.** В архиве уже есть libusb. В сборке используется локальная подпись. Если macOS заблокирует первый запуск, убедитесь, что скачали архив из этого репозитория, и выберите **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**.
- **Linux.** Релиз собран на Ubuntu 24.04. Для запуска нужны GTK 3 и libusb 1.0. На Ubuntu их можно установить командой `sudo apt install libgtk-3-0t64 libusb-1.0-0`. Чтобы подключаться к USB без запуска от root, сохраните правило ниже в `/etc/udev/rules.d/70-fnirsi-2c53t.rules`, выполните `sudo udevadm control --reload-rules` и переподключите прибор.
- **Windows.** Если Windows видит прибор как диск, а приложение не может открыть USB, прибору нужен совместимый с libusb драйвер, например WinUSB. В Zadig выбирайте устройство с USB ID **2e3c:5720**. Делайте это после прошивки. Пока назначен WinUSB, обычный USB-диск прибора может пропасть до возврата драйвера накопителя. Если Windows сообщит об отсутствующей библиотеке Visual C++, установите [компоненты Microsoft для x64](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist).

```udev
SUBSYSTEM=="usb", ATTR{idVendor}=="2e3c", ATTR{idProduct}=="5720", TAG+="uaccess"
```

USB-управление проверено с реальным 2C53T на Mac с Apple Silicon. Сборки Linux и Windows делает GitHub. Обмен с прибором на этих системах ещё предстоит проверить.

## Собрать прошивку у себя

Скачайте **2C53T Firmware V1.2.0** со [страницы загрузок FNIRSI](https://www.fnirsi.com/pages/manuals-firmwares) и распакуйте `APP_2C53T_V1.2.0_251015.bin`. Перед сборкой скрипт сверит SHA-256 именно этого файла. Исходный и готовый образы останутся у вас на компьютере.

Понадобятся Python 3.13 и Clang с поддержкой ARM. На macOS подойдёт Clang из Xcode Command Line Tools. На Ubuntu установите пакет `clang`. На Windows эти же команды можно выполнить в Ubuntu под WSL.

Выполните команды из корня репозитория, подставив путь к скачанному файлу.

```sh
python3.13 -m venv .venv
.venv/bin/python -m pip install -r firmware_mod/requirements.txt
.venv/bin/python firmware_mod/r6j/build_r6.py "/путь/к/APP_2C53T_V1.2.0_251015.bin"
```

Готовый файл появится в `firmware_mod/r6j/build/APP_2C53T_V1.2.0_RU_REMOTE_r6j.bin`. Скрипт напечатает его SHA-256 и сохранит рядом `manifest.json` со списком изменений. Патч добавляет управление по USB, русские меню, экспорт CSV на самом приборе и возможность прервать калибровку нуля.

**Установка с Windows 10/11.** Зарядите прибор, выключите его и подключите кабелем передачи данных. Удерживая **MENU**, включите прибор. Откройте диск **IAP**, скопируйте в его корень собранный файл `.bin` и дождитесь сообщения об успехе или перезапуска. До конца обновления оставьте подключёнными кабель и питание. Сохраните исходную прошивку на случай восстановления. FNIRSI рекомендует обновляться с Windows. [Инструкция производителя](https://www.fnirsi.com/pages/manuals-firmwares)

## Как снять сигнал

1. Откройте на 2C53T режим осциллографа, включите **USB Sharing** и подключите кабель передачи данных.
2. В приложении нажмите **Подключить**. На вкладке **Сигнал** задайте развёртку, масштаб канала и множитель щупа. Нажмите **Применить**.
3. Нажмите **Запуск** для живого просмотра, **Один кадр** для одиночного захвата или откройте **Захват**, чтобы задать триггер и записать серию. Приложение читает и проверяет каждый кадр перед следующим взведением.
4. На вкладке **Измерения** видны частота, период, длительность импульса, заполнение, минимум, максимум, среднее и размах. Курсоры измеряют разницу по времени и напряжению. **Декодер** разбирает UART и IrDA SIR по остановленному кадру, если в нём достаточно отсчётов на бит.
5. Кнопка **Сохранить кадр** добавляет остановленный кадр в нижнюю ленту. Нажмите **Наложить** на опорном кадре. Графики совместятся по моменту срабатывания триггера. В меню **Опыт** можно сохранить и открыть сеанс `.fnirsi` и выгрузить PNG или CSV.

Прибор передаёт 301 экранный отсчёт на канал при развёртке от 10 нс/дел до 20 мс/дел. Между кадрами серии есть паузы. Фильтр 20 МГц применяется к отображаемому сигналу.

Кнопка **Калибровать** на вкладке **Сигнал** запускает калибровку нуля. Сначала выньте оба щупа из BNC-входов. После калибровки нуля прибор может продолжать сообщать, что усиление не проверено. Пока это предупреждение видно, считайте значения напряжения приблизительными.

## Собрать и выпустить приложение

Установите [Flutter 3.41.9](https://docs.flutter.dev/install/archive) и инструменты сборки для своей системы. Из папки `scope_app`:

```sh
flutter pub get --enforce-lockfile
flutter analyze --no-pub
flutter test --no-pub
```

- **macOS.** Установите Xcode, CocoaPods и libusb (`brew install libusb`), затем выполните `bash tools/build_macos.sh`.
- **Linux.** Установите [зависимости Flutter для Linux](https://docs.flutter.dev/platform-integration/linux/setup) и libusb, затем выполните `flutter build linux --release`.
- **Windows.** В [Visual Studio](https://docs.flutter.dev/platform-integration/windows/setup) установите компонент **Разработка классических приложений на C++**. Укажите полный путь к x64-библиотеке `libusb-1.0.dll` в переменной `LIBUSB_DLL`, затем выполните `flutter build windows --release`.

Чтобы выпустить новую версию, отправьте на GitHub тег вида `v0.2.0`. [Desktop release](.github/workflows/release.yml) соберёт четыре пакета и опубликует их вместе с SHA-256, когда все сборки пройдут. Для проверки перед тегом тот же процесс можно запустить вручную на вкладке **Actions**.
