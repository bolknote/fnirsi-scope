2C53T r6: compatible capture protocol 0x00050001 + typed control 0x00060001

Device descriptor (unchanged): VID 2e3c, PID 5720, EP0 max packet 64.
Both additions use vendor/device/IN bmRequestType=0xc0. No interface claim,
USB reset, arbitrary memory access, firmware write or OUT payload is added.
They coexist with the original mass-storage class Setup and read-only LUN1.

bRequest=0x5a, wValue=operation, wIndex=argument, wLength<=64.
Operation 0 reads status; other operations queue one GUI-task command.
The command must be acknowledged before another command is submitted.
Interrupts only enqueue; acquisition and filesystem work run in task context.

Operations:
  0 status; 1 arm a new capture/series; 2 cancel; 3 mode (0 single,1 save,2 series)
  4 count 1..50; 5 gap 0..10000 ms; 6 timeout 1..600 seconds
  7 pretrigger percent 0..100; 8 digital filter mask 0..3
  9 trigger channel 0/1, enabled only; 10 edge 0/1
 11 trigger level signed int16 -100..100, native 1/25-division codes
 12 timebase 0..19; 13 SAVE current stopped frame; 14 open the panel.
Configurations cannot change during an active capture/series, except cancel.

Status is 16 little-endian uint32 values (64 bytes):
 0 magic 0x35465043
 1 version 0x00050001
 2 phase: 0 idle,1 arming,2 armed,3 saving,4 ready,5 gap,6 error,7 cancelled
 3 low16 error, high16 immediate command rejection
 4 monotonic frozen frame ID (not a native SAVE file number)
 5 CRC32 (IEEE) of the frozen 3600-byte state
 6 completed captures in this series
 7 target captures
 8 latest accepted command ID
 9 completed command ID (GUI has executed it)
10 mode
11 last successfully saved native file number, or 0
12 frozen byte count (3600 / 0xe10)
13 native millisecond tick, wrapping uint32
14 digital filter mask
15 pretrigger percentage

Errors: 0 success;1 busy;2 invalid;3 trigger timeout;4 SAVE/full album;
5 calibration/SPI busy/fault;6 no reserved memory;7 no frame;
8 unsupported timebase;9 not in oscilloscope mode.

bRequest=0x5b, wValue=offset, wIndex=frameID & 0xffff, wLength<=64.
Reads only within the reserved frozen frame. Wrong frame token, invalid range
or mid-copy produces zero-length data. A host must verify FULL frame ID before
and after transfer AND the independent CRC32; the 16-bit token alone is not
sufficient. The status is read live; the snapshot is published only after copy.

The frozen byte layout is the existing native state prefix at 0x200000f8:
  0x356 two 301-byte screen arrays
  0x5b0 bank 0, 1024 bytes; 0x9b0 bank 1, 1024 bytes
  0xdb4 window start uint16LE; 0xdb6 count uint16LE
plus the native input/trigger/calibration/acquisition parameters.
Do not infer raw ADC timing from these banks. The exporter retains the prior
CSV-v1 units and explicitly marks unknown calibration history on the host.

Native SINGLE completion, rather than any RUN->STOP transition, publishes
the frame. ARMED follows native PLAY, a 50-ms settling interval, empty FPGA
command queue and the native readiness GPIO. Real hardware timing is untested.
Only timebase indices 0..19 are accepted for automatic completed capture.

UI configuration is volatile. Calibration and original settings are not
written by this protocol. Internal rearm operation 15 is not accepted over USB.

R6 TYPED MEASUREMENT CONTROL

New operation numbers on 0x5A (wIndex is uint16, signed where indicated):
 16 channel mask 1..3; enable-before-disable, always retain a valid trigger
 17/18 CH1/CH2 native range index 0..9
 19/20 CH1/CH2 probe exponent 0=X1, 1=X10 (physical probe unchanged)
 21/22 CH1/CH2 coupling 0=AC, 1=DC
 23/24 CH1/CH2 offset int16 -100..100
 25 RUN, argument 0=NORMAL or 1=AUTO (native GS[17] values)
 26 STOP, argument 0; also clears failed/cancelled capture state
 27 STOP + freeze preview, argument 0; does not count a triggered SINGLE
 28 timebase index 0..19 through native handlers
 29 native trigger mode 0=NORMAL, 1=AUTO, 2=SINGLE; finishes STOPPED
 30 native trigger source 0=CH1, 1=CH2 (must be enabled)
 31 native trigger edge 0=rising, 1=falling
 32 native trigger level int16 -100..100
 33 arm completed-SINGLE capture from the native KEY task; argument 0,
    requires capture mode 0 (single without device SAVE) and STOP.

Use 33 for unattended host-only captures. Operations 1..14 retain compatibility.
All typed setting commands require STOP, except RUN/STOP/freeze. Only STOP
may interrupt an active capture. Configuration is refused during calibration
or SPI fault and outside normal scope/scope-settings/our own panel.
Changing trigger mode in stock firmware starts RUN; r6 restores STOP before
acknowledging operation 29. Offsets use native handlers, retaining dependent
threshold/range/DAC/PWM behavior. Firmware does not accept arbitrary keys.

USB IRQ only publishes the mailbox. GUI schedules one token to the original
KEY queue (handle at 0x20002d70). The 0x08040058 prefix hook consumes tokens
BEFORE native key-table indexing. The command remains outstanding until the
actual native action finishes. An unprocessed token expires after 2 seconds.
Native KEY stack is 240 words, 960 bytes; stock had only 128 words.
Preview waits >=50 ms, empty acquisition queue, native readiness GPIO and
nonempty native window, then copies/publishes a CRC frame in the scope task.
The one-second task wakes that task even while native RUN is stopped.

bRequest=0x5C, wValue=0, wIndex=0, wLength<=64: settings/readback only.
Unknown pages return zero length. Packet (64 bytes, uint32 fields LE):
  0 uint32 magic 0x364c5443
  4 uint32 version 0x00060001
  8 uint32 generation (odd while KEY is applying settings)
 12 uint32 last completed typed command ID (completion may contain an error)
 16 uint32 stage: 0 idle, 1 queued-for-KEY, 2 applying, 3 freezing
 20 uint32 last typed command error, same enum as 0x5A
 24..55 native STATE[0..31]:
   +0,+1 coupling; +2,+3 ranges; +4,+5 int8 offsets; +6,+7 probes
   +10,+11 FFT flags; +0x14 enabled mask; +0x15 channel config
   +0x16 trigger source; +0x17 mode; +0x18 edge
   +0x1A int16 horizontal trigger position; +0x1C int16 threshold
 56 byte native timebase index
 57 byte native RUN
 58 byte native UI mode (2 scope, 9 scope settings, 10 panel/native SAVE)
 59 byte native menu focus; 60 category; 61 row
 62 byte flags: bit0 calibration active, bit1 SPI fault,
               bit2 calibration required, bit3 math display active
 63 byte: bits0..1 digital-filter mask, bit4 frozen frame kind
          (0 triggered SINGLE, 1 explicit preview).

A host waits for stage idle / even generation and verifies each requested
field against readback. A transport ACK alone is not proof of configuration.
0x5A/0x5B are unchanged. 0x5C also acts as a volatile 10-second host keepalive;
any valid control/snapshot request renews it. Only idle poweroff is suppressed,
not the native low-battery handling. Disconnecting restores the idle policy.
